# 打刻メモ機能 — 要件 Q&A

## 基本仕様

### Q1. メモを入力できるタイミング
出勤打刻・退勤打刻の両方でメモを入力できるようにしますか？それとも片方だけ？

[回答]両方でメモできるようにする。

### Q2. メモの入力は必須か任意か
メモの入力は必須ですか？任意（空欄OK）ですか？

[回答]任意とする。

### Q3. メモの文字数制限
メモの最大文字数はどのくらいにしますか？（例: 100文字、200文字、制限なし）

[回答]200文字とする。

## UI / UX

### Q4. メモの入力方法
打刻ボタンを押す前にメモ欄が常に表示されている方式と、打刻ボタン押下後にダイアログで入力する方式、どちらが良いですか？

- A) 打刻ボタンの近くに常にテキスト入力欄を表示
- B) 打刻ボタン押下後にダイアログ（モーダル）でメモ入力 → 確定で打刻

[回答]Bでお願いします。

### Q5. メモの表示
入力したメモは「本日の打刻記録」一覧に表示しますか？

[回答]先頭10文字程度表示し詳細ボタンでダイアログが開き全文確認できる。

### Q5-1. 月次の勤怠履歴テーブルにもメモを表示しますか？
（Q5 が「はい」の場合に派生）

[回答]はい。仕様はQ5と同様とする。

## データ / バックエンド

### Q6. メモの保存先
現在の `attendance_records` テーブルにカラムを追加する形で良いですか？それとも別テーブル（打刻ごとに複数メモ等）にしますか？

[回答]テーブルにカラムを追加する。

### Q7. メモの種類
出勤メモと退勤メモを分けて保存しますか？（例: `clock_in_memo`, `clock_out_memo` の2カラム）それとも1つの `memo` カラムにまとめますか？

（Q1 で「両方」の場合に関連）

[回答]分けて保存する。

## 権限 / 閲覧範囲

### Q8. メモの閲覧権限
メモは本人だけが見られますか？それとも管理者・上長も閲覧できますか？

[回答]管理者と上長も閲覧できる。

### Q8-1. チーム勤怠一覧（管理者画面）にメモを表示しますか？
（Q8 で「管理者も閲覧可能」の場合に派生）

[回答]はい。Q5と同じ同じ仕様とする。

## その他

### Q9. メモの編集・削除
打刻後にメモを編集・削除することはできますか？

[回答]本人だけが編集・削除を出来るようにする。

### Q10. メモの用途・想定される内容
メモの主な用途を教えてください。（例: 遅刻理由、早退理由、リモート勤務の報告、業務内容メモ など）
用途によって入力候補やプレースホルダーの文言を検討します。

[回答]遅刻理由、早退理由の記載を主な用途とする。

## 追加質問（回答を受けて）

### Q11. ダイアログのスキップ操作（Q4 派生）
メモは任意（Q2）ですが、モーダル表示後に「メモなしで打刻する」導線はどうしますか？

- A) ダイアログに「スキップ」ボタンを用意し、メモ未入力でも打刻できる
- B) ダイアログに「メモを入力」欄＋「打刻する」ボタンのみ（空欄のまま押せばメモなし打刻）

[回答]Bでお願いします。

### Q12. メモ編集の期限（Q9 派生）
メモの編集・削除に期限はありますか？（例: 当日中のみ、翌日まで、無期限）

[回答]無期限

### Q13. プリセット選択肢の提案（Q10 派生・改善提案）
主な用途が遅刻・早退理由とのことですが、よく使う理由をワンタップで選べる「プリセット候補」を用意しますか？

例: 「電車遅延」「体調不良」「私用」「通院」などのチップを表示し、タップで入力欄に挿入。自由入力も可能。

- A) プリセット候補を用意する（よく使う理由をチップ表示）
- B) 自由入力のみ（プレースホルダーで例を示す程度）

[回答]Aだが、その他も用意し入力もできるようにする。

### Q14. 退勤メモのダイアログタイミング（Q4 派生・改善提案）
出勤時のメモは「遅刻理由」が主で入力動機が明確ですが、退勤時は早退以外だと書くことがないかもしれません。退勤時のダイアログ表示について：

- A) 出勤時と同様に毎回ダイアログを表示する
- B) 退勤ボタン長押し or 横の「メモ付き退勤」ボタンで任意表示（通常退勤はダイアログなしで即打刻）

[回答]Bでお願いします。

### Q15. プリセット候補の内容（Q13 派生）
出勤時と退勤時で表示するプリセット候補を分けますか？

- A) 分ける（出勤: 「電車遅延」「体調不良」「私用」「通院」 / 退勤: 「体調不良」「私用」「通院」「家庭の事情」など）
- B) 共通の候補セットを使う

また、プリセットの具体的な候補を教えてください。（上記の例でよければ「例の通り」でOKです）

[回答]例の通り。その他は追加してください。その他の時は自身で理由を入力です。

### Q16. 「メモ付き退勤」のUI（Q14 派生）
退勤は通常即打刻で、メモが必要なときだけダイアログを出す仕様ですが、その導線のUIはどれが良いですか？

- A) 退勤ボタンの横に小さい「メモ」アイコンボタンを配置（アイコン押下でダイアログ → メモ付き退勤）
- B) 退勤ボタンをドロップダウン化（「退勤」と「メモ付き退勤」の2選択肢）
- C) 退勤ボタン長押しでダイアログ表示（通常タップは即退勤）

[回答]Cでお願いします。
